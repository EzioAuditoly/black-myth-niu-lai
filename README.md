# 黑神话 · 牛来 🐂⚔️

一个 3D 网页动作冒险游戏（Three.js），致敬国产动画电影《牛来》与《黑神话：悟空》。
**纯前端、零构建、打开即玩。**

> ⚠️ **透明说明**：本项目由 **AI agent 协作**完成 —— 我负责需求拆解、agent 编排、接口与验收标准、集成调试、性能调优与部署；**代码主要由 AI 生成**。
>
> 我把它放上来，不是想证明"我会手写游戏"，而是想展示 **我如何用一套 AI 工作流，把东西从 0 做出来**。


## 🕹️ 操作

| 按键 | 功能 |
|---|---|
| `W A S D` | 角色移动 |
| `Space` | 闪避翻滚 |
| `J` | 轻攻击（−10 体力，伤害 15） |
| `K` | 重攻击（−25 体力，伤害 35） |
| `E` / `L` | 法术技能（−30 体力，范围伤害） |
| 鼠标移动 | 旋转视角 |

## ✨ 特色

- **动作战斗**：轻重攻击组合、连击数叠加（1 秒内连续攻击）影响伤害与特效
- **资源系统**：生命 100 / 体力 100（攻击与闪避消耗、自动恢复）
- **闪避翻滚**：精准时机闪避，消耗体力换取无敌帧
- **法术技能**：范围伤害 + 华丽特效
- **低多边形美术**：致敬《牛来》的视觉风格
- **粒子特效 / 动态光影**：实时阴影与受击反馈
- **敌人 AI**：智能行为与攻击判定
- **调试面板**：开发者友好的实时参数面板

## 🧠 我是怎么做的

- **需求拆解**：把"黑神话风格的动作战斗"拆成**可独立验证的模块**（战斗 / 连击 / 闪避 / 法术 / 粒子 / 敌人 AI / 调试面板）
- **agent 编排**：每个模块交给独立 agent，我先定**接口与验收标准**，再逐个集成
- **集成与调试**：（待补 2–3 个真实踩坑）
- **性能**：低多边形美术 + 复用几何体，目标稳定 60fps

## 🛠 技术栈

- **Three.js 0.160**（用 importmap 走 CDN，**无构建步骤、无依赖安装**）
- 原生 JavaScript（`game.js` 约 1100 行）+ Canvas
- 无后端

## 🚀 本地运行

```bash
python3 -m http.server 8124
# 主游戏：http://localhost:8124
# 测试页：http://localhost:8124/test.html
node test.js        # 跑一次自动化测试
```
