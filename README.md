# 黑神话 · 牛来 🐂⚔️

一个 3D 网页动作冒险游戏（Three.js），致敬国产动画电影《牛来》与《黑神话：悟空》。
**纯前端、零构建、打开即玩。**

> ⚠️ **透明说明**：本项目由 **AI agent 协作**完成 —— 我负责需求拆解、agent 编排、接口与验收标准、集成调试、性能调优与部署；**代码主要由 AI 生成**。
>
> 我把它放上来，不是想证明"我会手写游戏"，而是想展示 **我如何用一套 AI 工作流，把东西从 0 做出来**。

## 🔄 最近一次更新

初版是"白盒地面 + 战斗系统"，此后连推两层，`game.js` 从 1109 行涨到 **2996 行**：

**第一层 · 场景与物理**

- **地图重做**：白盒地面 → **青山绿水武侠风 3D 场景**（竹林 / 凉亭 / 溪流·桥 / 远山 / 山体平台），加软阴影
- **新增跳跃**：`Space` 起跳（初速 22、重力 −32，最高 ≈7.5m），可从中间 4m 平台再跳上 7m 山顶
- **操作修正**：`A/D` 明确为**原地左转/右转**（不是平移）；`Shift` 独立承担闪避翻滚，不再和 `Space` 抢
- **碰撞升级**：分离 X/Z 轴检测 → **贴墙滑行**；墙顶与平台都能站立行走
- **视角升级**：改为**右侧越肩第三人称**，随玩家朝向同步旋转
- **新增死亡系统**：血量归零或掉入虚空（y < −10）→ 死亡界面（死因 + 重来 / 退出）
- **新增 `ctl.sh`**：`start|stop|restart|status|open` 一行管理本地服务

**第二层 · 无限关卡**

- **关卡循环**：每关生成 `6 + 关卡×2` 只怪（L1=8 / L2=10 / L3=12…），全部清完后最高平台浮现**金球**，触碰即进下一关（无上限）
- **难度递增**：怪物血量 `80 + 关卡×20`、伤害 `8 + 关卡×2`
- **6 种随机风格**：青竹幽径 / 黄沙古道 / 雪山之巅 / 熔岩深处 / 紫晶夜境 / 樱花山谷 —— 各自决定天空、雾、地面、平台、装饰的整套色调
- **固定种子**：风格以关卡号为种子 → 第 N 关永远同一个风格（确定性，重载不变）
- **随机地形**：每关 4~8 个平台，位置/高度/大小在中央 ±15 范围内随机
- **关卡 HUD 与横幅**：顶部「第 X 关 | 风格名 | 剩余怪物」；切关时中央弹 2 秒「第 X 关 - 通关！进入第 X+1 关…」
- **资源回收**：切关时所有地形/墙/平台/装饰/怪物/金球 mesh 从 scene 移除并释放几何与材质

## 🎥 视角

- **右侧越肩第三人称**：相机贴在玩家右肩后上方，随玩家朝向同步旋转 —— 位置与朝向都跟 `player.rotation.y` 一起变，所以 A/D 转身时画面一起转
- 当前实参（`updateCamera()`）：右 **−1.4** / 身后 **3.4** / 上方 **3.4**，带平滑跟随
- ⚠️ 代码里那几行注释仍写着「右侧 0.7 / 身后 1.6 / 上方 1.4」，是**调优前的旧注释未同步**，以实参为准

## 💀 死亡系统

- **触发条件**：
  - 血量 ≤ 0
  - 掉入虚空（y < -10）
- **死亡界面**：黑屏 + 💀 + 死因 + 🔄重来 / 🚪退出
- **重来**：满血满体力复活到原点 (0,0,0)
- **退出**：隐藏 canvas，回到加载界面（刷新即重进）

## 🧱 物理与碰撞

- **跳跃**：初速度 22，重力 -32，最大跳跃高度 ≈ 7.5m（可从中间 4m 平台再跳上 7m 山顶）
- **碰撞**：分离 X / Z 轴检测，X 撞墙时只阻 X 方向移动，Z 方向仍可滑动 → **贴墙滑行**
- **墙顶可行走**：玩家站到墙上时，玩家脚高于墙顶 + 0.02 不再算碰撞 → 可以跳上 1.5m 矮墙走
- **可站立表面**：平台 + 墙顶都算（在玩家脚下水平范围内时）
- **跳跃穿越**：跳跃上升过程中（velocityY > 0.5），玩家头部越过墙顶 → 允许水平穿过
- **防卡墙内**：玩家站立时水平在墙内 → 强制推到最近边界外

## 🏯 关卡系统

- **关卡流程**：每关生成固定数量怪物（6 + 关卡 × 2，L1=8 / L2=10 / L3=12…），全杀光后最高平台出现金色金球，触碰进入下一关
- **怪物强度递增**：怪物血量 80 + 关卡 × 20，伤害 8 + 关卡 × 2
- **随机风格**：6 种风格（青竹幽径 / 黄沙古道 / 雪山之巅 / 熔岩深处 / 紫晶夜境 / 樱花山谷），决定天空/雾/地面/平台/装饰的色调
- **随机地形**：每关 4~8 个平台，位置/高度/大小随机分布在中央 ±15 范围内
- **固定种子**：每关风格用关卡号作种子，相同关卡号永远相同风格（确定性）
- **销毁旧关**：切换关时所有场景 mesh（地形/墙/平台/装饰/金球）从 scene 移除并释放几何/材质
- **关卡 HUD**：顶部显示「第 X 关 | 风格名 | 剩余怪物」
- **通关横幅**：切换关时中间弹出 2 秒横幅「第 X 关 - 通关！进入第 X+1 关...」

## 🚀 本地运行

```bash
python3 -m http.server 8124
# 主游戏：http://localhost:8124
# 测试页：http://localhost:8124/test.html
node test.js        # 跑一次自动化测试

# 或用 ctl.sh 一行管理
./ctl.sh start      # 起服务
./ctl.sh status     # 看状态
./ctl.sh open       # 浏览器打开
./ctl.sh stop       # 停掉
```
