│ 🎮 游戏操作 | Game Controls                                          │
├─────────────────────────────────────────────────────────────────────┤
│ W / A / S / D  ─────  角色移动 (Character Movement)                 │
│ Space          ─────  闪避翻滚 (Dodge Roll) [-20 体力]              │
│ J              ─────  轻攻击 (Light Attack) [15伤害, -10体力]       │
│ K              ─────  重攻击 (Heavy Attack) [35伤害, -25体力]       │
│ E / L          ─────  法术技能 (Magic Skill) [范围伤害, -30体力]     │
│ 鼠标移动        ─────  旋转视角 (Rotate Camera)                     │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│ ⚔️ 战斗策略 | Combat Strategy                                        │
├─────────────────────────────────────────────────────────────────────┤
│ • 连击系统: 1秒内连续攻击叠加连击数，提升伤害                          │
│ • 体力管理: 所有动作消耗体力，体力自动恢复 (每秒+20)                   │
│ • 重攻击重置: K键重攻击会重置连击计数，但造成高伤害                     │
│ • 技能范围: E/L技能对5米范围内敌人造成伤害                             │
│ • 闪避时机: 敌人攻击前翻滚可完全躲避伤害                               │
└─────────────────────────────────────────────────────────────────────┘
