## 🎮 游戏玩法

### 基础操作
1. **移动**: WASD 控制角色移动
2. **攻击**: J 轻攻击，K 重攻击
3. **技能**: E 或 L 释放法术
4. **闪避**: Space 翻滚闪避

### 战斗策略
1. 使用轻攻击积累连击数
2. 连击达到一定数量后使用重攻击造成高伤害
3. 注意体力管理，避免体力耗尽
4. 合理使用闪避躲避敌人攻击
5. 法术技能在敌人密集时使用效果最佳

### 资源管理
- **生命值**: 被攻击会减少，需要谨慎战斗
- **体力值**: 所有动作都消耗体力，会自动恢复
- **连击数**: 1秒内连续攻击叠加，重攻击会重置
